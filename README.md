# CampusOra
CampusOra is a web-based platform developed to help college students find affordable and verified off-campus accommodation near their campus when hostel rooms are unavailable. It enables room search based on location, budget, and distance, while allowing owners to list rooms securely.
CampusOra provides a centralized solution where students can discover off-campus rooms and PG accommodations near their college based on key parameters such as distance, rent, and facilities. Property owners can list their available rooms, and an admin module ensures verification and authenticity of listings.

The goal of CampusOra is to simplify the accommodation search process, eliminate dependency on brokers, and provide a safe, transparent, and student-centric housing solution.
