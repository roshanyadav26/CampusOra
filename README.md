🚀 CampusOra

Find Your Perfect Stay Near Campus

📌 Overview

CampusOra is a full-stack web application that helps students find nearby rental rooms and connect directly with property owners. It provides a seamless platform for room discovery, filtering, and real-time communication.

✨ Features
🏠 Browse rooms near your location
📍 Location-based search (Geolocation + Maps)
💬 Real-time chat between student and owner
🖼️ Image upload using Cloudinary
🔍 Advanced filters (rent, BHK, amenities)
📱 Fully responsive design
🔐 Authentication & Authorization system
